# Open Talk Placement Test Bot 🎓

An English level assessment Telegram bot based on CEFR levels.

## Features

- Grammar assessment
- Vocabulary assessment
- CEFR level detection
- Levels:
  - A1 Beginner
  - A2 Elementary
  - B1 Intermediate
  - B2 Upper-Intermediate
  - C1 Advanced

## Test Information

- Total Questions: 40
- Grammar Questions: 20
- Vocabulary Questions: 20
- Estimated Time: 15 minutes
